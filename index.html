Credit Card Fraud Detection - Model Benchmark and Evaluation¶

This notebook trains and compares four Machine Learning models for credit card fraud detection:

  1. Logistic Regression
  2. Random Forest Classifier
  3. AdaBoost Classifier
  4. K-Nearest Neighbors (KNN)

Pipeline Highlights:¶

  • Automated GPU detection (CuPy / RAPIDS cuML fallback to CPU scikit-learn)
  • Data cleaning and stratified splitting
  • Standardized feature scaling
  • Stratified K-Fold Cross-Validation
  • Comparative visualizations (ROC Curves, PR Curves, Confusion Matrices, Metric Summaries)

In [9]:
for name, model in models.items():
    print(f"Running pipeline for: {name}...")
    t0 = time.time()
    
    # 1. Stratified 5-Fold Cross Validation
    cv_scores = cross_validate(
        model, X_train_scaled, y_train, 
        cv=cv, 
        scoring=['accuracy', 'precision', 'recall', 'f1', 'roc_auc', 'average_precision'],
        n_jobs=-1
    )
    
    # 2. Fit on full training set and evaluate on test set
    model.fit(X_train_scaled, y_train)
    y_pred = model.predict(X_test_scaled)
    
    if hasattr(model, "predict_proba"):
        y_proba = model.predict_proba(X_test_scaled)[:, 1]
    else:
        y_proba = model.decision_function(X_test_scaled)
        
    elapsed = time.time() - t0
    
    # Test set metrics
    acc = accuracy_score(y_test, y_pred)
    prec = precision_score(y_test, y_pred, zero_division=0)
    rec = recall_score(y_test, y_pred)
    f1 = f1_score(y_test, y_pred)
    roc_auc = roc_auc_score(y_test, y_proba)
    pr_auc = average_precision_score(y_test, y_proba)
    
    # Store results
    results[name] = {
        'Accuracy': acc,
        'Precision': prec,
        'Recall': rec,
        'F1-Score': f1,
        'ROC-AUC': roc_auc,
        'PR-AUC': pr_auc,
        'CV F1 (Mean)': cv_scores['test_f1'].mean(),
        'CV ROC-AUC (Mean)': cv_scores['test_roc_auc'].mean(),
        'CV PR-AUC (Mean)': cv_scores['test_average_precision'].mean(),
        'Time (s)': elapsed
    }
    
    confusion_matrices[name] = confusion_matrix(y_test, y_pred)
    
    fpr, tpr, _ = roc_curve(y_test, y_proba)
    roc_curves[name] = (fpr, tpr, roc_auc)
    
    p_curve, r_curve, _ = precision_recall_curve(y_test, y_proba)
    pr_curves[name] = (p_curve, r_curve, pr_auc)
    
    print(f"Completed {name} in {elapsed:.2f}s")
    print(f"Test Recall: {rec:.4f} | Precision: {prec:.4f} | F1: {f1:.4f} | PR-AUC: {pr_auc:.4f}\n")
